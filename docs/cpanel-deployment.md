# cPanel deployment

cPanel is compatible only when the plan supports a long-running Node.js 20+ process, writable persistent storage, PostgreSQL connectivity, outbound WebSockets, HTTPS, configured environment variables, and process restart supervision. Use the cPanel Node.js application feature to install/start the app, point `WHATSAPP_AUTH_DIR` outside ephemeral release paths, and arrange a persistent PostgreSQL service. Some shared plans do not permit persistent workers or WebSocket egress; in that case host the gateway on a VPS and have the cPanel website's server-side code call the HTTPS API. Never place an API key in public browser code. Do not assume a reverse proxy under a URL subdirectory is available. This configuration has not been tested against a specific cPanel provider.
