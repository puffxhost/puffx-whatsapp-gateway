# Docker deployment

Copy `.env.example` to `.env`. Set random `SESSION_SECRET` and `API_KEY_PEPPER` values and a strong `POSTGRES_PASSWORD`. For production put the app behind a reverse proxy with HTTPS, set `PUBLIC_BASE_URL` to the public URL and `COOKIE_SECURE=true`. Start with `docker compose up -d --build`; monitor `docker compose logs -f gateway`. Postgres and WhatsApp auth data use persistent named volumes. Back up with `docker compose exec -T db pg_dump -U puffx puffx > backup.sql` and archive the `whatsapp_data` volume separately. Restore the database with `docker compose exec -T db psql -U puffx puffx < backup.sql`, then restore the auth volume with the gateway stopped. Upgrade by backing up, pulling/building, and restarting; roll back to the prior image and restore a matching database snapshot if a migration is not backward compatible. The bundled Nginx snippet is in `docker/nginx.conf`; provision TLS certificates with Certbot for your domain.
