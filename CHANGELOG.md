# Changelog

## 0.2.0 — 2026-10-30

- Rebuilt the dashboard with responsive session cards, live connection status, light and dark themes, accessible controls, overview statistics, and recent message history.
- Added server-sent events for session and QR updates, QR renewal, phone pairing in the same dialog, copyable codes, session reconnect/logout/delete controls, and failed-message retry.
- Recover stale session states after restarts and show clearer WhatsApp connection errors.

- Initial API, dashboard, Baileys adapter, PostgreSQL schema, Docker setup, and documentation.
